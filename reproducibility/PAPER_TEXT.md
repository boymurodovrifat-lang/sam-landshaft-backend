# Code and data availability — manuscript draft

Application source, installation instructions and current-input evaluation scripts are accessible at https://github.com/boymurodovrifat-lang/sam-landshaft-frontend and https://github.com/boymurodovrifat-lang/sam-landshaft-backend. The original application was implemented by Diyorbek Olimov; baseline commits are frontend `aafb4ce2cb50c7a3091c6e019614105f24f9e2b3` and backend `407316df1377f95aad9d75239c9555ec130a94e3`. The review candidate version is `v1.0.0-rc.1`; cite release tags and a version DOI only after publication. An open-source license is pending agreement. The backend reproducibility directory records software versions, current served input revisions and evaluation outputs. Input rasters are distributed separately and lack permanent identifiers and complete content checksums in this candidate. Public source access does not establish complete reproducibility of historical experiments.
