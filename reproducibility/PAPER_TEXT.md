# Code and data availability

Application source, installation instructions and current-input evaluation scripts are accessible at https://github.com/boymurodovrifat-lang/sam-landshaft-frontend and https://github.com/boymurodovrifat-lang/sam-landshaft-backend. Version v1.0.0-rc.2 adopts the MIT License, copyright (c) 2026 Rifat Boymurodov and Diyorbek Olimov. The version archive identifier is https://doi.org/10.5281/zenodo.23106387 (registered on Zenodo publication). The original application was implemented by Diyorbek Olimov; baseline commits are frontend `aafb4ce2cb50c7a3091c6e019614105f24f9e2b3` and backend `407316df1377f95aad9d75239c9555ec130a94e3`. The backend reproducibility directory records software versions, current served input revisions and evaluation outputs. Input rasters are distributed separately and lack permanent archive identifiers and complete content checksums. The MIT software license does not cover study rasters or override third-party reuse terms. Public source access does not establish complete reproducibility of historical experiments.
